# 🔥 Coolkid Hub

O Coolkid Hub é um site para compartilhar links de mods, addons, mapas, aplicativos e outros conteúdos.

## Recursos

- 🔍 Pesquisa de posts
- 📤 Compartilhamento por link
- 👤 Painel de administrador
- ☁️ Armazenamento com Supabase
- 📱 Interface responsiva

## Tecnologias

- HTML
- CSS
- JavaScript
- Supabase
- GitHub Pages
